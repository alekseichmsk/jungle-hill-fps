# Jungle Hill FPS

Браузерный концепт ретро-шутера в духе Doom/Blood (вдохновлён инди-игрой Hamburger Hill): джунгли Вьетнама, 1969.

**Играть:** https://alekseichmsk.github.io/jungle-hill-fps/

- Враги — пиксельные спрайты (Gemini), медленные зелёные трассеры можно уворачивать стрейфом
- Оружие: M16, дробовик, огнемёт (1–3 или кнопка «ОРУЖ»)
- Классическая панель снизу: отряд из 8 бойцов, лицо героя, часы, здоровье, патроны
- Телефон: джойстик слева, свайп справа, FIRE; ПК: WASD + мышь

Один файл `index.html`, Three.js с CDN, спрайты в `sprites/`.
